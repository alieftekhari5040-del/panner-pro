# 🎮 پنر پرو - سیستم گیمیفیکیشن شخصی

یک وب اپلیکیشن حرفه‌ای برای مدیریت چالش‌ها و مدال‌های شخصی با طراحی گیمیفیکیشن.

## ✨ امکانات

- **⚔️ مدیریت چالش‌ها** - چالش‌های شخصی بساز و مدیریت کن
- **🏆 سیستم ۱۰ مدال** - برای هر چالش ۱۰ مدال مختلف (آهنی تا خدایی)
- **📊 داشبورد آماری** - نمای کلی از پیشرفت‌ها
- **🎉 انیمیشن‌های حرفه‌ای** - Confetti و افکت‌های جذاب
- **🌐 آفلاین (PWA)** - بدون نیاز به اینترنت کار میکنه
- **💾 ذخیره محلی** - همه داده‌ها روی مرورگر خودت
- **🌙 تم تاریک** - طراحی مدرن و چشم‌نواز
- **🔤 فارسی RTL** - کاملاً فارسی و راست‌چین

## 🏅 مسیر ۱۰ مدال

1. 🪨 آهنی
2. 🥉 برنزی
3. 🥈 نقره‌ای
4. 🥇 طلایی
5. 💎 پلاتینی
6. 💠 الماسی
7. 🔥 افسانه‌ای
8. 🔮 اسطوره‌ای
9. ⚡ حماسی
10. 👑 خدایی

وقتی هر ۱۰ مدال رو بگیری، دور کلکسیون طلایی میشه! ✨

## 🚀 اجرا

```bash
npm install
npm run dev
```

سایت روی `http://localhost:3000` اجرا میشه.

## 🛠️ تکنولوژی‌ها

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- Framer Motion
- PWA (Service Worker)
