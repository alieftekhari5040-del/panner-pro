# 🎮 پنر پرو - Panner Pro

سیستم گیمیفیکیشن حرفه‌ای برای مدیریت چالش‌های شخصی و کسب مدال

## ✨ امکانات

- **⚔️ مدیریت چالش‌ها**: چالش‌های شخصی بسازید و پیشرفتتون رو دنبال کنید
- **🏅 سیستم ۱۰ سطحی مدال**: از برنزی تا نهایی - هر چالش ۱۰ مدال داره
- **🌟 حاشیه طلایی**: وقتی ۱۰ مدال یک چالش رو کامل کنید، حاشیه طلایی فعال میشه
- **📊 داشبورد آماری**: نمای کلی از تمام پیشرفت‌ها
- **🏆 دستاوردها**: دستاوردهای مختلف کسب کنید
- **🔥 سیستم Streak**: هر روز فعالیت کنید و streak بسازید
- **💾 بکاپ و بازیابی**: از داده‌هاتون بکاپ بگیرید
- **📱 PWA آفلاین**: بدون اینترنت هم کار میکنه!
- **🎨 طراحی گیمینگ**: رابط کاربری خفن با انیمیشن‌های حرفه‌ای
